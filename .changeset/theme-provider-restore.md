ThemeProvider now applies `defaultTheme` and restores the saved theme on load. It used to save each choice to `localStorage` but never read it back, and never put `defaultTheme` on `<html>`, so a reload returned to light, and `defaultTheme="dark"` rendered light while ThemeSwitch showed Dark. When it mounts, it puts on `<html>` the theme saved under `storageKey` (default `theme`), or `defaultTheme` (default `light`) when nothing valid is saved. It removes the other theme names, leaves other classes alone and saves nothing. A new `themes` prop lists the names it restores (default `["light", "dark"]`; `defaultTheme` always counts), each a single class name. `setTheme` still applies and saves any name. It now keeps its identity while `storageKey`, `defaultTheme` and the names in `themes` stay the same, even when `themes` is a new array. With storage blocked, as in a sandboxed iframe, it used to throw after changing the class, leaving `<html>` and the provider's `theme` out of step; the theme now lasts for the page's lifetime. A theme name other than `light` and `dark`, such as `system` in the ThemeSwitch docs' old Custom Themes sample, is now restored on load only if it is listed in ThemeProvider's `themes`, as in `<ThemeProvider themes={["light", "dark", "system"]}>`; otherwise choosing it still applies it, but it isn't restored, and it logs a warning once per name. `@amerfathullah/myds-react/utils`, which a Server Component can import, now exports `getThemeScript()`. It returns a script for `<head>` that applies the same theme before the page renders, so a user who chose Dark sees no flash of light. Pass it ThemeProvider's `storageKey`, `defaultTheme` and `themes`, and regenerate a copied script whenever they change. Code you added to read the saved theme, put its class on `<html>` and pass it as `defaultTheme` can go; if it ran before the page rendered, use `getThemeScript` in its place. The ThemeSwitch toggle now shows the provider's theme in its server HTML. A toggle rendered without a ThemeProvider now stays on Light when clicked, where before it flipped its icon and label without changing the theme; to fix it, wrap the app in ThemeProvider.
