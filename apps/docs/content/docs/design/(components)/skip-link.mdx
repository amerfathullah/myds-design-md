---
title: Skip link
description: Enables users to bypass repetitive navigation links and jump directly to the main content. It enhances accessibility for keyboard and screen reader users by improving navigation efficiency and is typically hidden until focused.
---

## Where to use?

Every `gov.my` page should have a skip link placed immediately after the `<body>` tag.

However, if a cookie banner is used, place skip links immediately after the cookie banner.

If `<header>` is present, skip links still come first (after the cookie banner, if one is used), outside any `<header>`. Do not wrap skip links inside `<nav>`.

```html
<body>
   <!-- Cookie banner, if used -->

   <!-- 1. Place skip links here -->
   <a href="#main-content">
      Skip to main content
   </a>

   <!-- Masthead -->
   <!-- Navbar -->

   <!-- 2. Main content -->
   <main id="main-content" tabindex="-1">
      <input>
   </main>

</body>
```

1. The skip link component, which links to the main content section's ID.
2. The main content section the skip link points to. Give it `tabindex="-1"`, so the skip link can move focus to it without adding a Tab stop. Don't add `tabindex="0"` to content that isn't interactive.

The example shows placement only. For the component, see the develop docs' [Skiplink](/docs/develop/skiplink) page.

## How it works

The skip link is hidden until it has focus. After the page loads, the first TAB shows it. If a cookie banner is shown, the banner's controls come first, and closing the banner moves focus to the skip link. When it appears, it is in a fixed position at the top left of the screen.

![skip-link-how-it-works.png](/design/skip-link-how-it-works.png)

1. When the user presses TAB, the skip link appears (instantly) in its focus state. Add a Shadow/context-menu shadow to show that it sits above other menus. Note: when the user clicks anywhere on the page, hide the skip link.
2. While the skip link has focus, pressing ENTER moves focus to the main content section, scrolls to it and hides the skip link. The next TAB moves focus to the first focusable element in that section.

## What if the user keeps pressing TAB?

If the user keeps pressing TAB after the skip link appears, focus moves in sequence to the next interactive elements on the page, following the natural Tab order.

![skip-link-press-tab.png](/design/skip-link-press-tab.png)

1. Focus on the first focusable element after the skip link: the Masthead's trigger ("Here's how you know"), then the Navbar's logo.
2. Focus on the second focusable element, and so on, following the natural Tab order.

The images and videos are design mockups. With MYDS's components, ENTER moves focus to the main content section, not to its first control. On a MYDS page, the Masthead's trigger and the Navbar's logo come before the menu in the Tab order.
