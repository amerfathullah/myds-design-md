## Penggunaan

```ts copy title="Import"
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbSeparator,
  BreadcrumbPage,
} from "@amerfathullah/myds-react/breadcrumb";
```

```tsx copy title="Anatomi" title="Anatomi"
export default () => (
  <Breadcrumb>
    <BreadcrumbItem>
      <BreadcrumbLink />
      <BreadcrumbPage />
    </BreadcrumbItem>
    <BreadcrumbSeparator />
  </Breadcrumb>
);
```

Pembaca skrin menyebut landmark `<nav>` breadcrumb sebagai "breadcrumb". Hantar `aria-label` kepada `Breadcrumb` untuk menamakannya dalam bahasa laman anda, contohnya `<Breadcrumb aria-label="Laluan halaman">`.

### Pautan vs Halaman

`BreadcrumbLink` digunakan untuk halaman induk, manakala `BreadcrumbPage` digunakan untuk halaman semasa. Halaman semasa biasanya tidak boleh diklik.

### Serpihan Ellipsis

Serpihan yang terlalu panjang akan dipendekkan dengan elipsis. Had lebar maksimum ialah `200px`. Pengguna boleh melayang di atas serpihan teks biasa untuk melihat teks penuh.

Serpihan dengan `children` yang bukan teks biasa, seperti ikon, `<span>`, komponen terjemahan atau `asChild` yang membalut pautan router, tidak memaparkan teks penuhnya apabila dilayang: berikan teks penuhnya dalam `title`. Namakan serpihan ikon sahaja dengan `aria-label`, bukan `title`, contohnya `aria-label="Laman utama"`.

<Tabs items={["Pratonton", "Kod"]}>
