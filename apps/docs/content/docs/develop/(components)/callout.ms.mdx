## Penggunaan

```ts copy title="Import"
import { Button } from "@amerfathullah/myds-react/button";
import {
  Callout,
  CalloutAction,
  CalloutClose,
  CalloutContent,
  CalloutTitle,
} from "@amerfathullah/myds-react/callout";
```

```tsx copy title="Anatomi"
export default () => (
  <Callout>
    <CalloutTitle />
    <CalloutContent />
    <CalloutAction>
      <CalloutClose />
    </CalloutAction>
  </Callout>
);
```

### Susun Atur

Callout yang mempunyai **tajuk** dan **tindakan** disusun secara **sebaris**, dalam satu baris.
Callout yang mempunyai **kandungan** (`CalloutContent`) disusun secara **bertindan**, dengan bahagiannya satu di bawah yang lain, sama ada ia mempunyai tindakan atau tidak.

### Boleh Dihapuskan

Jika callout boleh dihapuskan, anda boleh memaparkan **butang tutup** di sudut kanan atas callout dengan mengisytiharkan prop `dismissible`.
Untuk menangkap peristiwa hapus, anda boleh menggunakan prop `onDismiss`.

Pembaca skrin menyebut butang tutup sebagai "Close". Tetapkan `closeLabel` untuk menamakannya dalam bahasa laman anda, contohnya `closeLabel="Tutup"`.

Untuk menghapuskan callout melalui pendengar acara, balut elemen sasaran dengan `CalloutClose`. `CalloutClose` juga akan mencetuskan acara onDismiss, jika ditakrifkan.

### Pembaca skrin

Callout dipaparkan dengan `role="note"`. Pembaca skrin membacanya mengikut susunan bacaan bersama kandungan lain halaman, dan tidak menyebutnya apabila ia muncul. Ini sesuai untuk callout dalam kandungan halaman.

Apabila callout muncul selepas pengguna bertindak dan mesti didengar serta-merta, seperti ralat selepas penghantaran yang gagal, hantar `role="alert"`.

```tsx copy title="Ralat selepas penghantaran yang gagal"
import { useState, type FormEvent } from "react";
import { Button } from "@amerfathullah/myds-react/button";
import {
  Callout,
  CalloutContent,
  CalloutTitle,
} from "@amerfathullah/myds-react/callout";

export default function ApplicationForm() {
  const [error, setError] = useState(false);

  async function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const response = await fetch("/api/apply", {
      method: "POST",
      body: new FormData(event.currentTarget),
    });
    setError(!response.ok);
  }

  return (
    <form onSubmit={handleSubmit}>
      {error && (
        <Callout variant="danger" role="alert">
          <CalloutTitle>Permohonan anda tidak dihantar</CalloutTitle>
          <CalloutContent>Semak butiran anda dan cuba lagi.</CalloutContent>
        </Callout>
      )}
      {/* Medan borang */}
      <Button type="submit">Hantar</Button>
    </form>
  );
}
```

Ikon dan warna menunjukkan varian, tetapi kedua-duanya tidak sampai kepada pembaca skrin: Callout menyembunyikan ikon itu daripadanya. Oleh itu, perkataan dalam tajuk mesti menyebut varian, dalam bahasa laman anda. Sama ada:

- tulis tajuk supaya perkataannya menyebut varian, seperti "Permohonan anda tidak dihantar" dalam contoh di atas, atau
- mulakan tajuk dengan nama varian: Maklumat (`info`), Berjaya (`success`), Amaran (`warning`) atau Ralat (`danger`). Contohnya `<CalloutTitle>Ralat: Borang tidak dihantar</CalloutTitle>`.

Jika reka bentuk tidak dapat memaparkan perkataan itu, letakkannya dalam teks yang tersembunyi secara visual di awal tajuk: `<span className="sr-only">Ralat: </span>`. Gunakannya sebagai ganti nama yang dipaparkan, jangan sekali-kali bersama nama itu; jika tidak, pembaca skrin akan menyebut varian dua kali.

```tsx copy title="Varian disebut dalam tajuk"
// Nama varian, dipaparkan
<Callout variant="danger">
  <CalloutTitle>Ralat: Borang tidak dihantar</CalloutTitle>
  <CalloutContent>Semak butiran anda dan cuba lagi.</CalloutContent>
</Callout>

// Nama varian, tersembunyi secara visual, apabila reka bentuk tidak dapat memaparkannya
<Callout variant="danger">
  <CalloutTitle>
    <span className="sr-only">Ralat: </span>Borang tidak dihantar
  </CalloutTitle>
  <CalloutContent>Semak butiran anda dan cuba lagi.</CalloutContent>
</Callout>
```

Perkara ini paling penting apabila anda menghantar `role="alert"`. Pembaca skrin membaca teks callout sebaik sahaja ia muncul, dan tajuk yang tidak menyebut varian membiarkan pengguna tertanya-tanya sama ada ia ralat.
