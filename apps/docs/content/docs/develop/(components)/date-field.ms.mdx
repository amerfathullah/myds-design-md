## Penggunaan

```ts copy title="Import"
import { DateField } from "@amerfathullah/myds-react/date-field";
import { Label } from "@amerfathullah/myds-react/label";
```

## Contoh

### Saiz

Gunakan prop `size` untuk menukar saiz medan tarikh!

<Tabs items={["Pratonton", "Kod"]}>
  <Tab value="Pratonton">
    <div className="not-prose flex flex-col items-center gap-3">
      <div className="flex flex-col gap-2">
        <Label htmlFor="date-field-small" size="small">Tarikh lahir</Label>
        <DateField id="date-field-small" size="small" />
      </div>
      <div className="flex flex-col gap-2">
        <Label htmlFor="date-field-medium" size="medium">Tarikh lahir</Label>
        <DateField id="date-field-medium" size="medium" />
      </div>
      <div className="flex flex-col gap-2">
        <Label htmlFor="date-field-large" size="large">Tarikh lahir</Label>
        <DateField id="date-field-large" size="large" />
      </div>
    </div>
  </Tab>
  <Tab value="Kod">
    ```tsx
    <Label htmlFor="date-field-small" size="small">Tarikh lahir</Label>
    <DateField id="date-field-small" size="small" />
    <Label htmlFor="date-field-medium" size="medium">Tarikh lahir</Label>
    <DateField id="date-field-medium" size="medium" />
    <Label htmlFor="date-field-large" size="large">Tarikh lahir</Label>
    <DateField id="date-field-large" size="large" />
    ```
  </Tab>
</Tabs>

### Keadaan Tidak Terkawal vs Terkawal

Untuk menggunakan medan tarikh dalam keadaan tidak terkawal, tetapkan prop `defaultValue` kepada nilai awal medan tarikh.

Untuk menggunakan medan tarikh dalam keadaan terkawal, tetapkan prop `value` kepada nilai semasa medan tarikh dan sediakan pendengar acara `onValueChange` untuk mengendalikan perubahan.

<Tabs items={["Pratonton", "Kod"]}>
  <Tab value="Pratonton">
    <div className="not-prose flex flex-col gap-3 items-center">
      <div className="flex flex-col gap-2">
        <Label htmlFor="date-field-uncontrolled" size="small">Tidak Terkawal</Label>
        <DateField id="date-field-uncontrolled" defaultValue={NOW} />
      </div>
      <div className="flex flex-col gap-2">
        <Label htmlFor="date-field-controlled" size="small">Terkawal</Label>
        <DateField id="date-field-controlled" value={NOW} />
      </div>
    </div>
  </Tab>
  <Tab value="Kod">
    ```tsx
    // Keadaan tidak terkawal
    <Label htmlFor="date-field-uncontrolled" size="small">Tidak Terkawal</Label>
    <DateField id="date-field-uncontrolled" defaultValue={new Date().toISOString().split("T")[0]} />

    // Keadaan terkawal
    <Label htmlFor="date-field-controlled" size="small">Terkawal</Label>
    <DateField id="date-field-controlled" value={new Date().toISOString().split("T")[0]} />
    ```

  </Tab>
</Tabs>

### Dilumpuhkan

Medan tarikh boleh dilumpuhkan dengan menetapkan prop `disabled` kepada `true`. Apabila dilumpuhkan, medan tarikh tidak akan interaktif.

<Tabs items={["Pratonton", "Kod"]}>
  <Tab value="Pratonton">
    <div className="not-prose flex justify-center">
      <div className="flex flex-col gap-2">
        <Label htmlFor="date-field-disabled" size="small">Tarikh lahir</Label>
        <DateField id="date-field-disabled" defaultValue={NOW} disabled />
      </div>
    </div>
  </Tab>
  <Tab value="Kod">
    ```tsx
    <Label htmlFor="date-field-disabled" size="small">Tarikh lahir</Label>
    <DateField id="date-field-disabled" defaultValue={new Date().toISOString().split("T")[0]} disabled />
    ```
  </Tab>
</Tabs>

### Tidak Sah

Keadaan tidak sah dicetuskan apabila medan tarikh gagal pengesahan. Untuk menunjukkan medan tarikh tidak sah, tetapkan prop `invalid` kepada `true`.

<Tabs items={["Pratonton", "Kod"]}>
  <Tab value="Pratonton">
    <div className="not-prose flex justify-center">
      <div className="flex flex-col gap-2">
        <Label htmlFor="date-field-invalid" size="small">Tarikh lahir</Label>
        <DateField id="date-field-invalid" defaultValue={NOW} invalid />
      </div>
    </div>
  </Tab>
  <Tab value="Kod">
    ```tsx
    <Label htmlFor="date-field-invalid" size="small">Tarikh lahir</Label>
    <DateField id="date-field-invalid" defaultValue={new Date().toISOString().split("T")[0]} invalid />
    ```
  </Tab>
</Tabs>
