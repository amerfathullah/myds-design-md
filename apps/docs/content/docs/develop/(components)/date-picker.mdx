## Usage

```ts copy title="Import"
import { DatePicker } from "@amerfathullah/myds-react/date-picker";
import { Label } from "@amerfathullah/myds-react/label";
```

```tsx copy title="Anatomy"
export default () => (
  <>
    <Label id="date-of-birth" size="small">
      Date of birth
    </Label>
    <DatePicker aria-labelledby="date-of-birth" />
  </>
);
```

Name each date picker. Give a `Label` an `id`, and pass the same id to the picker's `aria-labelledby`, as above. Screen readers then announce the picker's button by the label's text, then the date it shows: "Date of birth 12 Mar 2024", or "Date of birth dd / mm / yyyy" before a date is chosen.

Unlike the date field, a `Label`'s `htmlFor` doesn't work here: the date picker takes no `id`, and a `Label` whose `htmlFor` matches nothing names nothing, with no error. Clicking the `Label` doesn't open the picker either.

If no visible label names the picker, pass an `aria-label` to name it in your site's language, for example `<DatePicker locale="ms" aria-label="Tarikh lahir" />`. Screen readers announce it, then the date. If you pass both, `aria-labelledby` wins. To describe the picker, for example with a hint under its label, pass the hint's id as `aria-describedby`.

### Uncontrolled vs Controlled State

To use the date picker in the uncontrolled state, set the `defaultValue` prop to the initial value of the date picker.

To use the date picker in the controlled state, set the `value` prop to the current value of the date picker and provide an `onValueChange` event listener to handle the change.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <div className="not-prose flex flex-col gap-3 items-center">
        <div>
            Uncontrolled
            <DatePicker defaultValue={NOW} />
        </div>
        <div>
            Controlled
            <DatePicker value={NOW} />
        </div>
    </div>
  </Tab>
  <Tab value="Code">
    ```tsx
    // Uncontrolled state
    <DatePicker defaultValue={new Date().toISOString().split("T")[0]} />

    // Controlled state
    <DatePicker value={new Date().toISOString().split("T")[0]} />
    ```

  </Tab>
</Tabs>

### Disabled

There are many ways to interact with DatePicker `disabled` state. Date picker can be disabled entirely by setting the `disabled` prop to `true`. A disabled `<fieldset>` around the `DatePicker` disables it too. Pass `disabled` to its `Label` as well, so the label dims too.

For a finer control on which dates to disable, you can pass a `Matcher | Matcher[]` that defines the rules for disabling dates.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <div className="not-prose space-y-2">
      <div className="flex items-center gap-3">
        Disable all dates
        <DatePicker defaultValue={NOW} disabled />
      </div>
      <div className="flex items-center gap-3">
        Disable dates before today
        <DatePicker defaultValue={NOW} disabled={{ before: new Date() }} />
      </div>
      <div className="flex items-center gap-3">
        Disable dates after today
        <DatePicker defaultValue={NOW} disabled={{ after: new Date() }} />
      </div>
      <div className="flex items-center gap-3">
        Disable dates outside of range
        <DatePicker
          defaultValue={NOW}
          disabled={{
            before: new Date().setDate(new Date().getDate() - 1),
            after: new Date().setDate(new Date().getDate() + 1),
          }}
        />
      </div>
      <div className="flex items-center gap-3">
        Disable dates by days of week (eg. Saturday and Sunday)
        <DatePicker
          defaultValue={NOW}
          disabled={{
            dayOfWeek: [0, 6],
          }}
        />
      </div>
      <div className="flex items-center gap-3">
        Disable dates by callback function (eg. disable every 13th of the month)
        <CustomDisableDatePicker />
      </div>
    </div>
  </Tab>
  <Tab value="Code">
    ```tsx
    // Disable all dates
    <DatePicker defaultValue={new Date()} disabled />
    
    // Disable dates before today
    <DatePicker defaultValue={new Date()} disabled={{ before: new Date() }} />

    // Disable dates after today
    <DatePicker defaultValue={new Date()} disabled={{ after: new Date() }} />

    // Disable dates outside of range
    <DatePicker
      defaultValue={new Date()}
      disabled={{
        before: new Date().setDate(new Date().getDate() - 1),
        after: new Date().setDate(new Date().getDate() + 1),
      }}
    />

    // Disable dates by days of week (eg. Saturday and Sunday)
    <DatePicker
      defaultValue={new Date()}
      disabled={{
        dayOfWeek: [0, 6],
      }}
    />

    // Disable dates by callback function (eg. disable every 13th of the month)
    <DatePicker
      defaultValue={new Date()}
      disabled={(date) => date.getDate() === 13}
    />
    ```

  </Tab>
</Tabs>

### Locale

To support common locales, you can pass the `locale` prop to the date picker.

Default value is English `en`. To switch to Bahasa Melayu, pass `ms`.

`locale` also sets what screen readers announce in the calendar: with `ms`, its buttons, grids, weekday headings and days have Malay names. The month view's year buttons are the exception. Screen readers announce them as "Go to the Previous Year" and "Go to the Next Year" unless `previousYearLabel` and `nextYearLabel` rename them. Set these in your site's language, for example `previousYearLabel="Pergi ke tahun sebelumnya"` and `nextYearLabel="Pergi ke tahun seterusnya"`.

        Bahasa Melayu
        <DatePicker defaultValue={NOW} locale="ms" />
      </div>
    </div>
  </Tab>
