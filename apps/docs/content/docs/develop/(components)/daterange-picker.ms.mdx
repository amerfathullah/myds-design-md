## Penggunaan

```ts copy title="Import"
import { DateRangePicker } from "@amerfathullah/myds-react/daterange-picker";
import { Label } from "@amerfathullah/myds-react/label";
```

```tsx copy title="Anatomi"
export default () => (
  <>
    <Label id="tarikh-perjalanan" size="small">
      Tarikh perjalanan
    </Label>
    <DateRangePicker locale="ms" aria-labelledby="tarikh-perjalanan" />
  </>
);
```

Namakan setiap pemilih julat tarikh. Berikan `id` kepada `Label`, dan hantar id yang sama kepada `aria-labelledby` pada pemilih, seperti di atas. Pembaca skrin kemudian menyebut setiap satu daripada dua butangnya dengan teks label, diikuti awalan dan tarikh yang dipaparkan butang itu: "Tarikh perjalanan Dari: 12 Mac 2024" dan "Tarikh perjalanan Hingga: 20 Mac 2024", atau "Tarikh perjalanan Dari: dd / mm / yyyy" sebelum tarikh dipilih. Awalan membezakan kedua-dua butang: "Dari:" dan "Hingga:" dengan `locale="ms"`, "From:" dan "To:" tanpanya, atau `fromLabel` dan `toLabel` anda sendiri.

Tidak seperti medan tarikh, `htmlFor` pada `Label` tidak berfungsi di sini: pemilih julat tarikh tidak menerima `id`, dan `Label` yang `htmlFor`nya tidak sepadan dengan apa-apa tidak menamakan apa-apa, tanpa sebarang ralat. Mengklik `Label` juga tidak membuka pemilih.

Jika tiada label yang kelihatan menamakan pemilih, hantar `aria-label` untuk menamakannya dalam bahasa laman anda, contohnya `<DateRangePicker locale="ms" aria-label="Tarikh perjalanan" />`. Pembaca skrin menyebutnya, diikuti awalan dan tarikh setiap butang: "Tarikh perjalanan Dari: 12 Mac 2024". Jika anda menghantar kedua-duanya, `aria-labelledby` diutamakan. Untuk menerangkan pemilih, contohnya dengan petunjuk di bawah labelnya, hantar id petunjuk itu sebagai `aria-describedby`.

### Keadaan Tidak Terkawal vs Terkawal

Untuk menggunakan pemilih julat tarikh dalam keadaan tidak terkawal, tetapkan prop `defaultValue` kepada nilai awal pemilih julat tarikh.

Untuk menggunakan pemilih julat tarikh dalam keadaan terkawal, tetapkan prop `value` kepada nilai semasa pemilih julat tarikh dan sediakan pendengar acara `onValueChange` untuk mengendalikan perubahan.

<Tabs items={["Pratonton", "Kod"]}>
  <Tab value="Pratonton">
    <div className="not-prose flex flex-col gap-3 items-center">
        <div>
            Tidak Terkawal
            <DateRangePicker defaultValue={{ from: YESTERDAY, to: TOMORROW }} />
        </div>
        <div>
            Terkawal
            <DateRangePicker value={{ from: YESTERDAY, to: TOMORROW }} />
        </div>
    </div>
  </Tab>
  <Tab value="Kod">
    ```tsx
    // Keadaan tidak terkawal
    <DatePicker defaultValue={{ from: new Date(/* semalam */), to: new Date(/* esok */) }} />

    // Keadaan terkawal
    <DatePicker value={{ from: new Date(/* semalam */), to: new Date(/* esok */) }} />
    ```

  </Tab>
</Tabs>

### Dilumpuhkan

Terdapat banyak cara untuk berinteraksi dengan keadaan `disabled` Pemilih Julat Tarikh. Pemilih julat tarikh boleh dilumpuhkan sepenuhnya dengan menetapkan prop `disabled` kepada `true`. `<fieldset>` yang dilumpuhkan di sekeliling `DateRangePicker` turut melumpuhkannya. Tetapkan juga `disabled` pada `Label` supaya label turut malap.

Untuk kawalan yang lebih halus pada tarikh yang hendak dilumpuhkan, anda boleh menghantar `Matcher | Matcher[]` yang mentakrifkan peraturan untuk melumpuhkan tarikh.

<Tabs items={["Pratonton", "Kod"]}>
  <Tab value="Pratonton">
    <div className="not-prose space-y-2">
      <div className="flex items-center gap-3">
        Lumpuhkan semua tarikh
        <DateRangePicker defaultValue={DEFAULT_DATERANGE} disabled />
      </div>
      <div className="flex items-center gap-3">
        Lumpuhkan tarikh sebelum semalam
        <DateRangePicker defaultValue={DEFAULT_DATERANGE} disabled={{ before: YESTERDAY }} />
      </div>
      <div className="flex items-center gap-3">
        Lumpuhkan tarikh selepas esok
        <DateRangePicker defaultValue={DEFAULT_DATERANGE} disabled={{ after: TOMORROW }} />
      </div>
      <div className="flex items-center gap-3">
        Lumpuhkan tarikh di luar julat
        <DateRangePicker
          defaultValue={DEFAULT_DATERANGE}
          disabled={{
            before: new Date().setDate(new Date().getDate() - 1),
            after: new Date().setDate(new Date().getDate() + 1),
          }}
        />
      </div>
      <div className="flex items-center flex-wrap gap-3">
        Lumpuhkan tarikh mengikut hari dalam minggu (cth. Sabtu dan Ahad)
        <DateRangePicker
          defaultValue={DEFAULT_DATERANGE}
          disabled={{
            dayOfWeek: [0, 6],
          }}
        />
      </div>
      <div className="flex items-center gap-3">
        Lumpuhkan tarikh mengikut fungsi panggilan balik (cth. lumpuhkan setiap 13hb bulan)
        <CustomDisableDateRangePicker />
      </div>
    </div>
  </Tab>
  <Tab value="Kod">
    ```tsx
    // Lumpuhkan semua tarikh
    <DateRangePicker defaultValue={{ from: new Date(/* semalam */), to: new Date(/* esok */) }} disabled />
    
    // Lumpuhkan tarikh sebelum semalam
    <DateRangePicker defaultValue={{ from: new Date(/* semalam */), to: new Date(/* esok */) }} disabled={{ before: new Date(/* semalam */) }} />

    // Lumpuhkan tarikh selepas esok
    <DateRangePicker defaultValue={{ from: new Date(/* semalam */), to: new Date(/* esok */) }} disabled={{ after: new Date(/* esok */) }} />

    // Lumpuhkan tarikh di luar julat
    <DateRangePicker
      defaultValue={{ from: new Date(/* semalam */), to: new Date(/* esok */) }}
      disabled={{
        before: new Date().setDate(new Date().getDate() - 1),
        after: new Date().setDate(new Date().getDate() + 1),
      }}
    />

    // Lumpuhkan tarikh mengikut hari dalam minggu (cth. Sabtu dan Ahad)
    <DateRangePicker
      defaultValue={{ from: new Date(/* semalam */), to: new Date(/* esok */) }}
      disabled={{
        dayOfWeek: [0, 6],
      }}
    />

    // Lumpuhkan tarikh mengikut fungsi panggilan balik (cth. lumpuhkan setiap 13hb bulan)
    <DateRangePicker
      defaultValue={{ from: new Date(/* semalam */), to: new Date(/* esok */) }}
      disabled={(date) => date.getDate() === 13}
    />
    ```

  </Tab>
</Tabs>

### Locale

Komponen ini menyokong dwibahasa, anda boleh menghantar prop `locale` untuk menetapkan bahasa digunakan.

Nilai lalai adalah `en` untuk English. Untuk menukar kepada Bahasa Melayu, tetapkan `ms`.

`locale` juga menetapkan apa yang disebut oleh pembaca skrin dalam kalendar Dari dan Hingga: dengan `ms`, butang, grid, tajuk hari dan hari kedua-dua kalendar mempunyai nama dalam Bahasa Melayu. Butang tahun dalam paparan bulan adalah pengecualian. Pembaca skrin menyebutnya sebagai "Go to the Previous Year" dan "Go to the Next Year" melainkan `previousYearLabel` dan `nextYearLabel` menamakannya semula dalam kedua-dua kalendar. Tetapkan kedua-duanya dalam bahasa laman anda, contohnya `previousYearLabel="Pergi ke tahun sebelumnya"` dan `nextYearLabel="Pergi ke tahun seterusnya"`.

<Tabs items={["Pratonton", "Kod"]}>
  <Tab value="Pratonton">
    <div className="not-prose flex justify-center gap-3">
      <div>
        English
        <DateRangePicker defaultValue={DEFAULT_DATERANGE} locale="en" />
      </div>
      <div>
        Bahasa Melayu
        <DateRangePicker defaultValue={DEFAULT_DATERANGE} locale="ms" />
      </div>
    </div>
  </Tab>
  <Tab value="Kod">
```tsx
<DatePicker defaultValue={{ from: new Date(/* semalam */), to: new Date(/* esok */) }} locale="en" />

<DatePicker defaultValue={{ from: new Date(/* semalam */), to: new Date(/* esok */) }} locale="ms" />
```
  </Tab>
