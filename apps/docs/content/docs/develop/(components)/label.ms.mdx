### Dilumpuhkan

Gunakan prop `disabled` untuk memalapkan label bagi medan yang dilumpuhkan. Ia menetapkan `data-disabled` pada label, yang memaparkan gaya dilumpuhkan, di mana-mana sahaja medan itu diletakkan. Label tidak melumpuhkan medan, jadi tetapkan juga `disabled` pada medan.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <div className="not-prose min-w-[360px] space-y-3">
      <div className="flex flex-col gap-2">
        <Label htmlFor="email-disabled" size="small" disabled>Alamat e-mel</Label>
        <Input id="email-disabled" type="email" defaultValue="name@example.com" disabled />
      </div>
      <div className="flex justify-between items-center">
        <Label htmlFor="checkbox-disabled" disabled>Padamkan notifikasi secara automatik</Label>
        <Checkbox id="checkbox-disabled" disabled />
      </div>
    </div>
  </Tab>
  <Tab value="Code">

import { Label } from "@amerfathullah/myds-react/label";
