## Penggunaan

```ts copy title="Import"
import {
  Masthead,
  MastheadHeader,
  MastheadContent,
  MastheadTitle,
  MastheadTrigger,
  MastheadSection,
} from "@amerfathullah/myds-react/masthead";
```

```tsx copy title="Anatomi"
export default () => (
  <Masthead>
    <MastheadHeader>
      <MastheadTitle />
      <MastheadTrigger />
    </MastheadHeader>
    <MastheadContent>
      <MastheadSection />
    </MastheadContent>
  </Masthead>
);
```

Teks yang anda hantar sebagai `children` `MastheadTrigger` menamakannya untuk pembaca skrin dan input suara, pada setiap lebar skrin. Di bawah `sm:`, pencetus hanya memaparkan ikon anak panah, dan teks itu disembunyikan secara visual tetapi masih menamakannya. Tanpa `children`, pencetus dinamakan "Toggle masthead"; hantar `aria-label` untuk menamakannya dalam bahasa laman anda, contohnya `<MastheadTrigger aria-label="Kenal pasti begini" />`. `aria-label` juga menggantikan teks `children` sebagai nama. Jika anda menghantar kedua-duanya, pastikan `aria-label` mengandungi teks yang kelihatan, supaya pengguna yang mengawal laman dengan suara boleh menyebut apa yang mereka lihat. `children` tanpa teks, seperti ikon sahaja, memerlukan `aria-label`.

Masthead bukan landmark dengan sendirinya: ia memaparkan `<div id="masthead">` biasa, sebelum `<header>` `Navbar`. Jadi tajuk dan penerangannya berada di luar semua landmark. Pengguna pembaca skrin yang bergerak mengikut landmark melangkauinya, dan semakan axe ke atas seluruh halaman melaporkannya di bawah peraturan `region`. Jadikan Masthead kawasan halaman yang dinamakan oleh tajuknya: hantar `role="region"` kepada `Masthead`, berikan `id` kepada `MastheadTitle`, dan halakan `aria-labelledby` `Masthead` kepada id itu, seperti contoh di bahagian atas halaman ini.

```tsx copy title="Kawasan halaman"
<Masthead role="region" aria-labelledby="masthead-title">
  <MastheadHeader>
    <MastheadTitle id="masthead-title">
      Portal Rasmi Kerajaan Malaysia
    </MastheadTitle>
    <MastheadTrigger>Kenal pasti begini</MastheadTrigger>
  </MastheadHeader>
  <MastheadContent>{/* MastheadSection */}</MastheadContent>
</Masthead>
```

Pembaca skrin kemudian menyebut kawasan bernama "Portal Rasmi Kerajaan Malaysia", iaitu teks tajuk itu sendiri, jadi nama itu mengikut bahasa laman anda tanpa rentetan baharu untuk diterjemahkan. Id itu mesti unik pada halaman. Untuk nama yang lain, hantar `role="region"` bersama `aria-label` sebagai ganti, contohnya `aria-label="Laman web rasmi kerajaan"`. Jika anda menghantar kedua-duanya, `aria-labelledby` diutamakan.

- **Sentiasa namakan kawasan itu.** `role="region"` tanpa nama lulus peraturan `region` axe, tetapi pelayar tidak mendedahkannya sebagai landmark, jadi Masthead masih berada di luar semua landmark.
- **Jangan namakan Masthead tanpa `role="region"`.** Ia `<div>` biasa, dan ARIA tidak membenarkan anda memberikan `aria-label` atau `aria-labelledby` kepadanya.

## Props

Setiap bahagian meneruskan `ref`nya kepada elemen yang dipaparkannya. Ref `Masthead` ialah `<div id="masthead">`nya, bukan elemen boleh lipat yang membalutnya.
