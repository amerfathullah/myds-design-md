## Usage

```ts copy title="Import"
import {
  Navbar,
  NavbarLogo,
  NavbarMenu,
  NavbarMenuItem,
  NavbarMenuDropdown,
  NavbarAction,
} from "@amerfathullah/myds-react/navbar";
```

```tsx copy title="Anatomy"
export default () => {
  return (
    <Navbar>
      <NavbarLogo />
      <NavbarMenu>
        <NavbarMenuItem />
        <NavbarMenuDropdown>
          <NavbarMenuItem />
        </NavbarMenuDropdown>
      </NavbarMenu>
      <NavbarActionGroup />
    </Navbar>
  );
};
```

### Navbar Menu

Screen readers announce the menu's `<nav>` landmark as "Main". Pass an `aria-label` to `NavbarMenu` to name it in your site's language, for example `<NavbarMenu aria-label="Utama">`. Or pass `aria-labelledby` with the id of a heading that names it.

### Navbar Action

On screens narrower than 1280px, `NavbarAction` also shows a button that opens and closes the mobile menu. Screen readers announce it as "Open navigation menu", or "Close navigation menu" while the menu is open. An `aria-label` on `NavbarAction` replaces both names, for example `aria-label="Menu navigasi"`. The button then no longer tells screen readers whether the menu is open.
