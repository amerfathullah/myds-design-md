## Usage

## Simple Usage

For simple usage, `AutoPagination` can be used directly. It is a pre-assembled component that handles common pagination use cases.

```ts copy title="Import"
import { AutoPagination } from "@amerfathullah/myds-react/pagination";
```

```tsx copy title="Anatomy"
<AutoPagination />
```

Screen readers announce the `default` type's previous and next buttons as "previous page" and "next page", each page button as "page" and its number, such as "page 3", and each ellipsis as "More pages". The `simple` and `full` types show "Previous" and "Next" on their buttons, and that text names them. Set `previousLabel`, `nextLabel`, `pageLabel` and `ellipsisLabel` to name them in your site's language. The `<nav>` landmark is announced as "pagination"; pass an `aria-label` to rename it, for example `aria-label="Penomboran"`.

```tsx copy title="Malay names"
<AutoPagination
  page={2}
  limit={10}
  count={200}
  type="default"
  onPageChange={(page) => console.log(page)}
  aria-label="Penomboran"
  previousLabel="Halaman sebelumnya"
  nextLabel="Halaman seterusnya"
  pageLabel={(page) => `Halaman ${page}`}
  ellipsisLabel="Lebih banyak halaman"
/>
```

In the `simple` and `full` types the labels are shown, so shorter text reads better there, for example `previousLabel="Sebelumnya"` and `nextLabel="Seterusnya"`.

### Advanced Usage

For user that requires more advanced use cases, the pagination functionality can be assembled manually. The user can use the subcomponents: `Pagination`, `PaginationItem`, `PaginationContent`, `PaginationEllipsis`, `PaginationNext`, `PaginationPrevious` and `PaginationNumber`.

```ts copy title="Import"
import {
  Pagination,
  PaginationContext,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
  PaginationNext,
  PaginationNumber,
  PaginationPrevious,
} from "@amerfathullah/myds-react/pagination";
```

```tsx copy title="Anatomy"
<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious />
    </PaginationItem>
    <PaginationItem>
      <PaginationNumber />
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis />
    </PaginationItem>
    <PaginationItem>
      <PaginationNext />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

Each part has an English name for screen readers, and an `aria-label` replaces it: on `Pagination` for the landmark ("pagination"), on `PaginationPrevious` and `PaginationNext` ("previous page" and "next page"), and on `PaginationNumber` ("page 3" on page 3's button). `PaginationEllipsis` announces "More pages"; pass children to replace it, for example `<PaginationEllipsis>Lebih banyak halaman</PaginationEllipsis>`.

Children name `PaginationPrevious` and `PaginationNext` in place of the default, so `<PaginationPrevious>Sebelumnya</PaginationPrevious>` is named "Sebelumnya". Children with no text, such as an icon alone, need an `aria-label`. With `asChild`, `PaginationPrevious` and `PaginationNext` add no name: name your own element, for example with an `aria-label`.

```tsx copy title="Malay names"
<Pagination
  aria-label="Penomboran"
  count={180}
  limit={10}
  page={4}
  onPageChange={(page) => console.log(page)}
  type="default"
>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious aria-label="Halaman sebelumnya" />
    </PaginationItem>
    <PaginationItem>
      <PaginationNumber number={3} aria-label="Halaman 3" />
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis>Lebih banyak halaman</PaginationEllipsis>
    </PaginationItem>
    <PaginationItem>
      <PaginationNext aria-label="Halaman seterusnya" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

### AutoPagination Types

Use the `type` props to change the type of the `AutoPagination` component. Examples of use cases for each types are outlined below:

1. **default**: Ideal for contexts where users might want to jump to a specific page within a large number of pages.
2. **simple**: Suitable for simpler navigation where users primarily move forward or backward.
3. **full**: Similar to the `simple` type, this type displays the current page and total pages on the left and navigation buttons on far right.

### Pagination Configurations

Opting into using `AutoPagination` or manual assembly of pagination subcomponents necessitates into the usage of props such as `page`, `limit` and `count`. The functionality and look of the pagination components will be influenced by them.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview" className="not-prose">
    <div className="flex flex-col gap-10 justify-center items-center">
      <p className="text-md font-bold">AutoPagination</p>
      <AutoPagination
        page={2}
        limit={10}
        count={200}
        type="simple"
        maxDisplay={4}
      />
      <p className="text-md font-bold">Manual assembly</p>
      <SelfPagination page={4} count={180}/>
    </div>
  </Tab>
  <Tab value="Code">
    ```tsx 
    import { AutoPagination } from "@amerfathullah/myds-react/pagination";

    // simple type
    <AutoPagination
      page={2}
      limit={10}
      count={200}
      type="simple"
      maxDisplay={4}
    />

    // self assembly
    const count = 180;
    const limit = 10;
    const page = 4;
    const { visiblePages, max } = usePagination({ count, limit, page });
    const pageFn = (page: number) => console.log(page);

    <Pagination
      count={count}
      limit={limit}
      page={page}
      onPageChange={pageFn}
      type="default"
    >
      <PaginationContent>
        <PaginationItem>
          <PaginationPrevious onClick={() => pageFn(page - 1)} />
        </PaginationItem>

        {visiblePages.map((pageNum, index) => (
          <PaginationItem key={index}>
            {pageNum === "..." ? (
              <PaginationEllipsis />
            ) : (
              <PaginationNumber number={pageNum as number} />
            )}
          </PaginationItem>
        ))}

        <PaginationItem>
          <PaginationNext onClick={() => pageFn(page + 1)} />
        </PaginationItem>
      </PaginationContent>
    </Pagination>

    ```

  </Tab>
</Tabs>

### PaginationContent

A layout component rendered as an unordered list `ul` that arranges `PaginationItem` in a horizontal row.

### PaginationItem

A wrapper component rendered as a list item `li` that contains individual pagination elements like `PaginationNext`, `PaginationPrevious`, `PaginationLabel` and `PaginationEllipsis`.

### PaginationNext

A button component that handles navigaton to the next page. The underlying component can be substituted by using the `asChild` props.

With no children, it shows only a chevron and its accessible name is "next page". Pass an `aria-label` to replace it, for example `aria-label="Halaman seterusnya"`. Children replace that name, so children with no text, such as an icon alone, need an `aria-label`. With `asChild` it adds no name: name your own element.

### PaginationPrevious

A button component that handles navigaton to the previous page. The underlying component can be substituted by using the `asChild` props.

With no children, it shows only a chevron and its accessible name is "previous page". Pass an `aria-label` to replace it, for example `aria-label="Halaman sebelumnya"`. Children replace that name, so children with no text, such as an icon alone, need an `aria-label`. With `asChild` it adds no name: name your own element.

### PaginationLabel

A text component that displays pagination information.

### PaginationEllipsis

A visual indicator component that represents skipped page numbers in the pagination sequence, rendered as three dots using an icon.

Screen readers announce it as "More pages", which isn't shown. Pass children to replace it, for example `<PaginationEllipsis>Lebih banyak halaman</PaginationEllipsis>`. The icon is hidden from screen readers.
