## Penggunaan

### Penggunaan Mudah

Komponen `AutoPagination` boleh digunakan terus untuk penggunaan mudah. Komponen ini boleh digunakan untuk tujuan paginasi lazim.

```ts copy title="Import"
import { AutoPagination } from "@amerfathullah/myds-react/pagination";
```

```tsx copy title="Anatomi"
<AutoPagination />
```

Pembaca skrin menyebut butang sebelumnya dan seterusnya bagi jenis `default` sebagai "previous page" dan "next page", setiap butang halaman sebagai "page" diikuti nombornya, seperti "page 3", dan setiap elipsis sebagai "More pages". Jenis `simple` dan `full` memaparkan "Previous" dan "Next" pada butangnya, dan teks itu yang menamakannya. Tetapkan `previousLabel`, `nextLabel`, `pageLabel` dan `ellipsisLabel` untuk menamakannya dalam bahasa laman anda. Elemen `<nav>` disebut sebagai "pagination"; hantar `aria-label` untuk menamakannya semula, contohnya `aria-label="Penomboran"`.

```tsx copy title="Nama dalam bahasa Melayu"
<AutoPagination
  page={2}
  limit={10}
  count={200}
  type="default"
  onPageChange={(page) => console.log(page)}
  aria-label="Penomboran"
  previousLabel="Halaman sebelumnya"
  nextLabel="Halaman seterusnya"
  pageLabel={(page) => `Halaman ${page}`}
  ellipsisLabel="Lebih banyak halaman"
/>
```

Dalam jenis `simple` dan `full`, label ini dipaparkan, jadi teks yang lebih pendek lebih sesuai, contohnya `previousLabel="Sebelumnya"` dan `nextLabel="Seterusnya"`.

### Penggunaan Lanjutan

Sebagai alternatif kepada komponen `AutoPagination`, fungsi paginasi masih dapat dilaksanakan dengan kombinasi subkomponen: `Pagination`, `PaginationItem`, `PaginationContent`, `PaginationEllipsis`, `PaginationNext`, `PaginationPrevious`, `PaginationNumber` dan `PaginationLabel`.

```ts copy title="Import"
import {
  Pagination,
  PaginationContext,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
  PaginationLabel,
  PaginationNext,
  PaginationNumber,
  PaginationPrevious,
} from "@amerfathullah/myds-react/pagination";
```

```tsx copy title="Anatomi"
<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious />
    </PaginationItem>
    <PaginationItem>
      <PaginationNumber />
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis />
    </PaginationItem>
    <PaginationItem>
      <PaginationNext />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

Setiap subkomponen mempunyai nama dalam bahasa Inggeris untuk pembaca skrin, dan `aria-label` menggantikannya: pada `Pagination` bagi elemen `nav` ("pagination"), pada `PaginationPrevious` dan `PaginationNext` ("previous page" dan "next page"), dan pada `PaginationNumber` ("page 3" bagi butang halaman 3). `PaginationEllipsis` menyebut "More pages"; hantar `children` untuk menggantikannya, contohnya `<PaginationEllipsis>Lebih banyak halaman</PaginationEllipsis>`.

`children` menamakan `PaginationPrevious` dan `PaginationNext` menggantikan nama lalai, jadi `<PaginationPrevious>Sebelumnya</PaginationPrevious>` dinamakan "Sebelumnya". `children` tanpa teks, seperti ikon sahaja, memerlukan `aria-label`. Dengan `asChild`, `PaginationPrevious` dan `PaginationNext` tidak menambah nama: namakan elemen anda sendiri, contohnya dengan `aria-label`.

```tsx copy title="Nama dalam bahasa Melayu"
<Pagination
  aria-label="Penomboran"
  count={180}
  limit={10}
  page={4}
  onPageChange={(page) => console.log(page)}
  type="default"
>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious aria-label="Halaman sebelumnya" />
    </PaginationItem>
    <PaginationItem>
      <PaginationNumber number={3} aria-label="Halaman 3" />
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis>Lebih banyak halaman</PaginationEllipsis>
    </PaginationItem>
    <PaginationItem>
      <PaginationNext aria-label="Halaman seterusnya" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

## Contoh

### Jenis AutoPagination

Gunakan props `type` untuk menukar jenis komponen `AutoPagination`. Contoh penggunaan untuk setiap jenis adalah seperti berikut:

1. **default**: Sesuai untuk keadaan di mana pengguna mungkin ingin melompat ke halaman tertentu dalam jumlah halaman yang banyak.
2. **simple**: Sesuai untuk navigasi yang lebih mudah di mana pengguna hanya bergerak ke muka surat sebelum atau selepas.
3. **full**: Serupa dengan jenis `simple`, jenis ini memaparkan halaman semasa dan jumlah halaman di sebelah kiri berserta butang navigasi di sebelah kanan.

### Konfigurasi Paginasi

Penggunaan `AutoPagination` atau pemasangan manual subkomponen paginasi memerlukan penggunaan `prop` seperti `page`, `limit` dan `count`. Fungsi dan rupa komponen paginasi akan dipengaruhi oleh prop-prop tersebut.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview" className="not-prose">
    <div className="flex flex-col gap-10 justify-center items-center">
      <p className="text-md font-bold">AutoPagination</p>
      <AutoPagination
        page={2}
        limit={10}
        count={200}
        type="simple"
        maxDisplay={4}
      />
      <p className="text-md font-bold">Manual assembly</p>
      <SelfPagination page={4} count={180}/>
    </div>
  </Tab>
  <Tab value="Code">
    ```tsx 
    import { AutoPagination } from "@amerfathullah/myds-react/pagination";

    // simple type
    <AutoPagination
      page={2}
      limit={10}
      count={200}
      type="simple"
      maxDisplay={4}
    />

    // self assembly
    const count = 180;
    const limit = 10;
    const page = 4;
    const { visiblePages, max } = usePagination({ count, limit, page });
    const pageFn = (page: number) => console.log(page);

    <Pagination
      count={count}
      limit={limit}
      page={page}
      onPageChange={pageFn}
      type="default"
    >
      <PaginationContent>
        <PaginationItem>
          <PaginationPrevious onClick={() => pageFn(page - 1)} />
        </PaginationItem>

        {visiblePages.map((pageNum, index) => (
          <PaginationItem key={index}>
            {pageNum === "..." ? (
              <PaginationEllipsis />
            ) : (
              <PaginationNumber number={pageNum as number} />
            )}
          </PaginationItem>
        ))}

        <PaginationItem>
          <PaginationNext onClick={() => pageFn(page + 1)} />
        </PaginationItem>
      </PaginationContent>
    </Pagination>

    ```

  </Tab>
</Tabs>

### PaginationContent

Komponen yang dirender sebagai elemen `ul` yang bertujuan untuk menyusun `PaginationItem` dalam arah mendatar.

### PaginationItem

Komponen yang dirender sebagai elemen `li` yang mengandungi elemen seperti `PaginationNext`, `PaginationPrevious`, `PaginationLabel` dan `PaginationEllipsis`.

### PaginationNext

Komponen `button` yang mengendalikan navigasi ke halaman seterusnya. Komponen lalai tersebut boleh digantikan dengan menggunakan props `asChild`.

Tanpa `children`, ia hanya memaparkan ikon anak panah dan nama boleh capainya ialah "next page". Hantar `aria-label` untuk menggantikannya, contohnya `aria-label="Halaman seterusnya"`. `children` menggantikan nama itu, jadi `children` tanpa teks, seperti ikon sahaja, memerlukan `aria-label`. Dengan `asChild`, ia tidak menambah nama: namakan elemen anda sendiri.

### PaginationPrevious

Komponen `button` yang mengendalikan navigasi ke halaman sebelumnya. Komponen lalai tersebut boleh digantikan dengan menggunakan props `asChild`.

Tanpa `children`, ia hanya memaparkan ikon anak panah dan nama boleh capainya ialah "previous page". Hantar `aria-label` untuk menggantikannya, contohnya `aria-label="Halaman sebelumnya"`. `children` menggantikan nama itu, jadi `children` tanpa teks, seperti ikon sahaja, memerlukan `aria-label`. Dengan `asChild`, ia tidak menambah nama: namakan elemen anda sendiri.

### PaginationLabel

Komponen teks yang memaparkan maklumat paginasi. Secara lalai, ia memaparkan `Page {page} of {totalPages}`, contohnya "Page 2 of 20", hanya apabila `type` `Pagination` ialah `full`. Dengan `default` atau `simple`, ia tidak memaparkan apa-apa. Hantar `content` untuk memaparkan teks anda sendiri di tempatnya, walau apa pun `type`, contohnya `content="Halaman 2 daripada 20"`.

### PaginationEllipsis

Komponen penunjuk visual yang mewakili nombor halaman yang dilangkau dalam urutan pagination.

Pembaca skrin menyebutnya sebagai "More pages", yang tidak dipaparkan. Hantar `children` untuk menggantikannya, contohnya `<PaginationEllipsis>Lebih banyak halaman</PaginationEllipsis>`. Ikonnya disembunyikan daripada pembaca skrin.
