## Usage

```ts copy title="Import"
import {
  Radio,
  RadioButton,
  RadioHintText,
  RadioItem,
  RadioLabel,
} from "@amerfathullah/myds-react/radio";
```

```tsx copy title="Anatomy"
<Radio>
  <RadioItem>
    <RadioButton value="apple" id="apple" />
    <RadioLabel htmlFor="apple">Apple</RadioLabel>
  </RadioItem>
  <RadioItem>
    <RadioButton value="banana" id="banana" />
    <div>
      <RadioLabel htmlFor="banana">Banana</RadioLabel>
      <RadioHintText>Comes pre-packaged.</RadioHintText>
    </div>
  </RadioItem>
</Radio>
```

### Controlled Component

To use `Radio` as a controlled component, set the `value` and `onValueChange` props.

```tsx
const [value, setValue] = useState("")

<Radio value={value} onValueChange={setValue}>
  {/* ... */}
</Radio>
```

### RadioItem

`RadioItem` uses the same props as a regular `div` element.

### RadioHintText

`RadioHintText` uses the same props as a regular `div` element. It describes the `RadioButton` in its `RadioItem`: screen readers read it after the radio's name, which the `RadioLabel` gives, not as part of the name. The `RadioButton` points its `aria-describedby` at each hint in its item, in order, before any ids you pass it, so you don't wire the hint yourself. Clicking the hint doesn't select the radio; clicking the `RadioLabel` does. In a disabled `RadioItem` or `Radio`, the hint is marked `aria-disabled`, as part of the inactive option.
