## Usage

```ts copy title="Import"
import {
  Radio,
  RadioButton,
  RadioHintText,
  RadioItem,
  RadioLabel,
} from "@amerfathullah/myds-react/radio";
```

```tsx copy title="Anatomi"
<Radio>
  <RadioItem>
    <RadioButton value="apple" id="apple" />
    <RadioLabel htmlFor="apple">Apple</RadioLabel>
  </RadioItem>
  <RadioItem>
    <RadioButton value="banana" id="banana" />
    <div>
      <RadioLabel htmlFor="banana">Banana</RadioLabel>
      <RadioHintText>Comes pre-packaged.</RadioHintText>
    </div>
  </RadioItem>
</Radio>
```

### Komponen Terkawal

Untuk menggunakan `Radio` sebagai komponen terkawal, tetapkan prop `value` dan `onValueChange`.

```tsx
const [value, setValue] = useState("")

<Radio value={value} onValueChange={setValue}>
  {/* ... */}
</Radio>
```

### RadioHintText

`RadioHintText` menggunakan prop yang sama seperti elemen `div` biasa. Ia menerangkan `RadioButton` dalam `RadioItem`nya: pembaca skrin membacanya selepas nama radio, yang diberikan oleh `RadioLabel`, bukan sebagai sebahagian daripada nama itu. `RadioButton` menunjukkan `aria-describedby`nya kepada setiap petunjuk dalam itemnya, mengikut susunan, sebelum sebarang id yang anda berikan kepadanya, jadi anda tidak perlu menyambungkan petunjuk itu sendiri. Mengklik petunjuk tidak memilih radio; mengklik `RadioLabel` memilihnya. Dalam `RadioItem` atau `Radio` yang dinyahaktifkan, petunjuk ditanda dengan `aria-disabled`, sebagai sebahagian daripada pilihan yang tidak aktif.
