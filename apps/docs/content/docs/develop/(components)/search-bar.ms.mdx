## Usage

```ts copy title="Import"
import {
SearchBar,
SearchBarInput,
SearchBarInputContainer,
SearchBarSearchButton,
SearchBarResults,
SearchBarResultsList,
SearchBarResultsItem,
SearchBarClearButton,
SearchBarHint,
} from "@amerfathullah/myds-react/search-bar";
````

```tsx copy title="Anatomi"
export default () => (
  <SearchBar size="large">
    <SearchBarInputContainer>
      <SearchBarInput aria-label="Cari nama" value={query} onValueChange={setQuery} />
      <SearchBarHint>
        Press <Pill size="small">/</Pill> to search
      </SearchBarHint>
      <SearchBarClearButton />
      <SearchBarSearchButton />
    </SearchBarInputContainer>
    <SearchBarResults open={true}>
      <SearchBarResultsList>
        <SearchBarResultsItem value="foo" onSelect={...} >
          Foo
        </SearchBarResultsItem>
        <SearchBarResultsItem value="bar" onSelect={...} >
          Bar
        </SearchBarResultsItem>
      </SearchBarResultsList>
    </SearchBarResults>
  </SearchBar>
);
```

`SearchBarSearchButton` dan `SearchBarClearButton` hanya memaparkan ikon. Pembaca skrin menyebut butang carian sebagai "Search" dalam semua saiz, dan butang kosongkan sebagai "Clear". Hantar `aria-label` untuk menamakan setiap satu dalam bahasa laman anda, contohnya `aria-label="Cari"` dan `aria-label="Kosongkan"`.

### Label yang Kelihatan

Contoh lain menamakan input carian dengan `aria-label`, yang tidak dipaparkan. Untuk memaparkan label, berikan `id` kepada `Label`, dan hantar id yang sama kepada `aria-labelledby` pada `SearchBarInput`. Pembaca skrin kemudian menyebut input dengan teks label.

`htmlFor` pada `Label` tidak berfungsi di sini: cmdk sendiri yang menetapkan `id` input, jadi `id` yang anda hantar kepada `SearchBarInput` tidak sampai kepada input, dan `Label` itu tidak menamakan apa-apa. Mengklik `Label` ini juga tidak memfokuskan input.

## Props

Setiap bahagian meneruskan `ref`nya kepada elemen yang dipaparkannya. Ref `SearchBarInput` ialah `<input>`nya.

`SearchBar` disarikan daripada `Command.Root` cmdk. Sila rujuk rujukan API dalam [dokumentasi ini](https://github.com/pacocoursey/cmdk#command-cmdk-root).

### SearchBarInput

`SearchBarInput` disarikan daripada `Command.Input` cmdk. Sila rujuk rujukan API dalam [dokumentasi ini](https://github.com/pacocoursey/cmdk#input-cmdk-input)

Nama boleh capainya datang daripada `aria-labelledby`nya, kemudian `aria-label`nya, kemudian `label` pada `SearchBar`: yang pertama anda hantar diutamakan. Nilai yang kosong atau hanya mengandungi ruang dikira sebagai tidak dihantar. Ia tidak mempunyai nama lalai, dan teks pemegang tempatnya tidak menamakannya. `id` tidak sampai kepada input, kerana cmdk sendiri yang menetapkan `id` input, jadi `htmlFor` pada `Label` tidak dapat menamakannya. Sebaliknya, berikan `id` kepada `Label` dan hantar id itu kepada `aria-labelledby`, seperti [di atas](#label-yang-kelihatan).

### SearchBarInputContainer

`SearchBarInputContainer` menggunakan prop yang sama seperti elemen `div` biasa.

### SearchBarSearchButton

`SearchBarSearchButton` menggunakan prop yang sama seperti MYDS' `Button`. Sila rujuk rujukan API dalam [dokumentasi ini](/docs/develop/button)

Nama boleh capainya ialah "Search" secara lalai. Hantar `aria-label` untuk menggantikannya, contohnya `aria-label="Cari"`.

### SearchBarClearButton

`SearchBarClearButton` menggunakan prop yang sama seperti MYDS' `Button`. Sila rujuk rujukan API dalam [dokumentasi ini](/docs/develop/button)

Nama boleh capainya ialah "Clear" secara lalai. Hantar `aria-label` untuk menggantikannya, contohnya `aria-label="Kosongkan"`.

### SearchBarHint

### SearchBarResultsList

`SearchBarResultsList` disarikan daripada `Command.List` cmdk. Sila rujuk rujukan API dalam [dokumentasi ini](https://github.com/pacocoursey/cmdk#list-cmdk-list)

Nama boleh capainya ialah "Suggestions" secara lalai. Hantar `aria-label` untuk menggantikannya, contohnya `aria-label="Cadangan"`. Prop `label` cmdk juga menamakannya, tetapi `aria-label` diutamakan jika anda menghantar kedua-duanya.
