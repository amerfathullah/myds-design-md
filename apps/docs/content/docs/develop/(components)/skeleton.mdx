## Usage

```ts copy title="Import"
import { Skeleton } from "@amerfathullah/myds-react/skeleton";
```

```tsx copy title="Anatomy"
export default () => <Skeleton />;
```

### Skeleton or Spinner?

- Use a **Skeleton** when you know the layout of the content that is loading, such as a list, a card or a table. It holds the content's space, so the page does not jump when the content arrives.
- Use a [**Spinner**](/docs/develop/spinner) when an action is in progress, such as submitting a form, or when you don't know what shape the result will take.

## Examples

### Shapes

Use the `shape` prop to match the content being loaded. Set the size with `className`.

- `line` (default): a full-width pill bar for a line of text.
- `circle`: a round placeholder for avatars and icons.
- `block`: a placeholder with rounded corners for images, cards and media.

### Multiple lines

There is no multi-line helper. Map over `Skeleton` to draw as many lines as you need.

          <Skeleton key={index} className={width} />
        ))}

## Accessibility

Every `Skeleton` renders `aria-hidden="true"`, so screen readers skip it. Telling people that content is loading is up to you: set `aria-busy="true"` on the region that is loading and put visually hidden "Loading…" text inside it. Remove both when the content arrives.

```tsx copy title="Loading region"
import { Skeleton } from "@amerfathullah/myds-react/skeleton";

<section aria-busy={isLoading}>
  {isLoading ? (
    <>
      <span className="sr-only">Loading…</span>
      <Skeleton shape="block" className="h-32 w-full" />
      <Skeleton />
      <Skeleton className="w-2/3" />
    </>
  ) : (
    <Content />
  )}
</section>;
```

When the user has asked for reduced motion (`prefers-reduced-motion`), the skeleton stops shimmering and shows a flat fill.
