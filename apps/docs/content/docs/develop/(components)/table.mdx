## Usage

```ts copy title="Import"
import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,
} from "@amerfathullah/myds-react/table";
```

```tsx copy title="Anatomy"
export default () => (
  <Table>
    <TableHeader>
      <TableRow>
        <TableHead />
      </TableRow>
    </TableHeader>
    <TableBody>
      <TableRow>
        <TableCell />
      </TableRow>
    </TableBody>
    <TableCaption />
  </Table>
);
```

### TableTooltip

`TableTooltip` puts a question-mark icon in a header cell and shows its `children` as a tooltip. The icon is the tooltip's trigger, a button: hovering over it or focusing it opens the tooltip. Its hit area is at least 24×24px, centred on the 16px icon, so it is easier to hover over. The icon, the header's layout and the focus ring around the icon stay as they are.

Screen readers announce the trigger as "Tooltip". Pass an `aria-label` to name it in your site's language, for example `<TableTooltip aria-label="Maklumat">`.

`open`, `defaultOpen`, `onOpenChange`, `delayDuration` and `disableHoverableContent` go to the tooltip root, Radix UI's `Tooltip`. Every other prop goes to the trigger button, and so does a `ref`: for example `className`, `id`, `style`, `type`, event handlers, and `data-*` and `aria-*` attributes.

A header cell is named by its content, so the trigger's name joins the header's: screen readers announce a header holding "Umur" and a trigger named "Maklumat" as "Umur Maklumat". To keep the header's name to its text, put the text in an element with an id, and name the `TableHead` from it with `aria-labelledby`. `useId` gives each header its own id. Or give the `TableHead` an `aria-label` with its text. DataTable already names each header from its text, so its `meta.tooltip` needs neither.

```tsx
import { useId } from "react";
import { TableHead, TableTooltip } from "@amerfathullah/myds-react/table";

function AgeHeader() {
  const labelId = useId();
  return (
    <TableHead aria-labelledby={labelId}>
      <div className="flex items-center gap-1">
        <span id={labelId}>Umur</span>
        <TableTooltip aria-label="Maklumat">Umur dalam tahun</TableTooltip>
      </div>
    </TableHead>
  );
}
```
