import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,

  <Table>

### TableTooltip

`TableTooltip` meletakkan ikon tanda soal dalam sel tajuk dan memaparkan kandungan `children` sebagai tooltip. Ikon itu ialah pencetus tooltip, iaitu sebuah butang: mengarahkan kursor ke atasnya atau memfokuskannya membuka tooltip. Kawasan sasarannya berukuran sekurang-kurangnya 24×24px, berpusat pada ikon 16px, jadi lebih mudah untuk mengarahkan kursor ke atasnya. Ikon, susun atur tajuk dan cincin fokus di sekeliling ikon kekal seperti sedia ada.

Pembaca skrin menyebut pencetus itu sebagai "Tooltip". Hantar `aria-label` untuk menamakannya dalam bahasa laman anda, contohnya `<TableTooltip aria-label="Maklumat">`.

`open`, `defaultOpen`, `onOpenChange`, `delayDuration` dan `disableHoverableContent` dihantar kepada akar tooltip, iaitu `Tooltip` Radix UI. Setiap prop lain dihantar kepada butang pencetus, begitu juga `ref`: contohnya `className`, `id`, `style`, `type`, pengendali peristiwa, serta atribut `data-*` dan `aria-*`.

Sel tajuk dinamakan oleh kandungannya, jadi nama pencetus turut menjadi sebahagian daripada nama tajuk: pembaca skrin menyebut tajuk yang mengandungi "Umur" dan pencetus bernama "Maklumat" sebagai "Umur Maklumat". Untuk mengekalkan nama tajuk kepada teksnya sahaja, letakkan teks itu dalam elemen yang mempunyai id, dan namakan `TableHead` daripadanya dengan `aria-labelledby`. `useId` memberikan setiap tajuk id tersendiri. Atau berikan `TableHead` `aria-label` dengan teksnya. DataTable sudah menamakan setiap tajuk daripada teksnya, jadi `meta.tooltip` tidak memerlukan kedua-duanya.

```tsx
import { useId } from "react";
import { TableHead, TableTooltip } from "@amerfathullah/myds-react/table";

function AgeHeader() {
  const labelId = useId();
  return (
    <TableHead aria-labelledby={labelId}>
      <div className="flex items-center gap-1">
        <span id={labelId}>Umur</span>
        <TableTooltip aria-label="Maklumat">Umur dalam tahun</TableTooltip>
      </div>
    </TableHead>
  );
}
```
