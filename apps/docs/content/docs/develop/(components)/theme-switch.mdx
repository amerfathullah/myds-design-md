## Usage

```ts copy title="Import"
import { ThemeProvider } from "@amerfathullah/myds-react/hooks";
import { ThemeSwitch } from "@amerfathullah/myds-react/theme-switch";
```

```tsx copy title="Anatomy"
export default () => (
  <ThemeProvider>
    <ThemeSwitch />
  </ThemeProvider>
);
```

The bridge needs next-themes to keep the theme as a class on `<html>` (`attribute="class"`), as Fumadocs does. Here is a short version of it. Render it under next-themes' provider:

```tsx title="components/theme-bridge.tsx"
"use client";

import { ThemeContext } from "@amerfathullah/myds-react/hooks";
import { useTheme } from "next-themes";
import { useMemo, useSyncExternalStore, type ReactNode } from "react";

const subscribe = () => () => {};

export function ThemeBridge({ children }: { children: ReactNode }) {
  const { resolvedTheme, setTheme } = useTheme();
  // next-themes knows the theme only in the browser, so the server HTML shows light
  const mounted = useSyncExternalStore(
    subscribe,
    () => true,
    () => false,
  );
  const theme = (mounted && resolvedTheme) || "light";
  const value = useMemo(
    () => ({ theme, setTheme, defaultTheme: "light" }),
    [theme, setTheme],
  );

  return (
    <ThemeContext.Provider value={value}>{children}</ThemeContext.Provider>
  );
}
```

### Custom Themes

You can also extend themes available by defining the `themes` property! This also lets you to customize the theme icons or change up the order of themes.

Pass the same names to ThemeProvider's `themes`, so the theme a user picks is restored on load. The MYDS style preset styles only the light theme and `.dark`. Under ThemeProvider, any other name, `system` included, is only a class on `<html>` for you to style. So choosing System there shows the light theme, unless you style `.system`. ThemeProvider has no choice that follows the OS setting.

In the live example below, System follows your OS setting only because this site feeds `ThemeContext` from next-themes.

## Avoid a flash of the wrong theme

ThemeProvider restores the saved theme when React mounts it. The browser can show the page before then, in the light theme. So a user who chose Dark sees a flash of light first.

To avoid it, run the script that `getThemeScript` returns in `<head>`. It puts on `<html>` the theme ThemeProvider would pick, before the page renders. Pass `getThemeScript` the same `storageKey`, `defaultTheme` and `themes` as ThemeProvider. For example, with `<ThemeProvider defaultTheme="dark">`, use `getThemeScript({ defaultTheme: "dark" })`. The script never throws: if storage is blocked, it uses `defaultTheme`.

An app that feeds `ThemeContext` from next-themes doesn't need this, because next-themes runs its own script.

### Next.js App Router

The root layout is a Server Component. It can import `getThemeScript`, because `@amerfathullah/myds-react/utils` creates no React context. The script changes the class on `<html>` before React hydrates, so add `suppressHydrationWarning` to `<html>`.

```tsx title="app/layout.tsx"
import { getThemeScript } from "@amerfathullah/myds-react/utils";
import type { ReactNode } from "react";
import { Providers } from "./providers";

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        <script dangerouslySetInnerHTML={{ __html: getThemeScript() }} />
      </head>
      <body>
        <Providers>{children}</Providers>
      </body>
    </html>
  );
}
```

ThemeProvider creates a React context, so render it from a separate `"use client"` file. Its options must match the script's.

```tsx title="app/providers.tsx"
"use client";

import { ThemeProvider } from "@amerfathullah/myds-react/hooks";
import type { ReactNode } from "react";

export function Providers({ children }: { children: ReactNode }) {
  return <ThemeProvider>{children}</ThemeProvider>;
}
```

### Plain `index.html`

In an app without server rendering, such as Vite, put the script in `index.html`. This is the script for the default options:

{/* prettier-ignore */}
```html title="index.html"
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <script>
      (function k(t,e,n){let i=n.indexOf(e)===-1?n.concat([e]):n,o=e;try{let r=window.localStorage.getItem(t);r!==null&&i.indexOf(r)!==-1&&(o=r)}catch(r){}let s=document.documentElement.classList;for(let r=0;r!==i.length;r++)s.remove(i[r]);return s.add(o),o})("theme","light",["light","dark"])
    </script>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```

<Callout
  type="warn"
  title="Important"
  className="bg-bg-warning-50 text-txt-warning border-transparent"

>
  A copied script holds ThemeProvider's options. Regenerate it whenever they
