## Penggunaan

```ts copy title="Import"
import { TimeField } from "@amerfathullah/myds-react/time-field";
import { Label } from "@amerfathullah/myds-react/label";
```

```tsx copy title="Anatomi"
export default () => (
  <>
    <Label htmlFor="time-field" size="small">Masa temu janji</Label>
    <TimeField id="time-field" />
  </>
);
```

`TimeField` tidak memaparkan label atau id sendiri. Berikan `id` kepadanya dan namakannya dengan `Label` yang `htmlFor`nya sepadan. Ikon jam hanyalah hiasan dan disembunyikan daripada teknologi bantuan.

### Paparan 12 atau 24 jam

Medan masa memaparkan jam 12 jam (dengan AM/PM) atau jam 24 jam mengikut lokaliti pelayar dan sistem pengendalian pengguna. Ia tidak boleh ditetapkan oleh komponen. Apa pun yang dilihat pengguna, nilainya sentiasa dalam format 24 jam `HH:mm` (contohnya `"16:30"`), atau `HH:mm:ss` apabila `step` kurang daripada 60.

### Medan masa atau slot masa?

- Gunakan **`TimeField`** apabila pengguna boleh memasukkan sebarang masa, seperti masa sesuatu kejadian berlaku.
- Gunakan **[slot masa](#slot-masa)** apabila pengguna menempah daripada kekosongan yang tetap, seperti masa temu janji di kaunter.

### Keadaan Tidak Terkawal vs Terkawal

Untuk menggunakan medan masa dalam keadaan tidak terkawal, tetapkan prop `defaultValue` kepada masa awal sebagai rentetan 24 jam `HH:mm`.

Untuk menggunakan medan masa dalam keadaan terkawal, tetapkan prop `value` dan kemas kininya daripada pendengar acara `onChange`.

<Tabs items={["Pratonton", "Kod"]}>
  <Tab value="Pratonton">
    <div className="not-prose flex justify-center">
      <div className="flex flex-col gap-2">
        <Label htmlFor="time-field-uncontrolled" size="small">Tidak terkawal</Label>
        <TimeField id="time-field-uncontrolled" defaultValue="16:30" />
      </div>
    </div>
  </Tab>
  <Tab value="Kod">
    ```tsx
    // Keadaan tidak terkawal
    <Label htmlFor="time-field-uncontrolled" size="small">Tidak terkawal</Label>
    <TimeField id="time-field-uncontrolled" defaultValue="16:30" />

    // Keadaan terkawal
    const [time, setTime] = useState("16:30");

    <Label htmlFor="time-field-controlled" size="small">Terkawal</Label>
    <TimeField
      id="time-field-controlled"
      value={time}
      onChange={(e) => setTime(e.target.value)}
    />
    ```

  </Tab>
</Tabs>

### Langkah

`step` adalah dalam saat dan lalainya `60`, jadi medan memaparkan jam dan minit tanpa saat. Tetapkan `step={900}` untuk langkah 15 minit: kekunci anak panah dan kawalan putar pelayar menggerakkan minit sebanyak 15.

Pelayar menganggap `step` sebagai peraturan pengesahan. Tidak semua pelayar menghalang pengguna menaip minit lain (seperti `16:07`); input kemudiannya ditanda `:invalid` dan gagal pengesahan borang. Semak nilainya semasa hantar, atau gunakan [slot masa](#slot-masa) apabila hanya masa tetap dibenarkan.

## Slot masa

Apabila pengguna menempah daripada kekosongan yang tetap, seperti temu janji kaunter setiap 15 minit, tawarkan masa yang tersedia sebagai pilihan dalam [`Select`](/docs/develop/select) dan bukannya `TimeField`. Pengguna hanya boleh memilih masa yang benar-benar ditawarkan, dan anda menentukan cara setiap masa ditulis.

Gunakan masa 24 jam `HH:mm` sebagai `value` setiap pilihan, dan tulis labelnya mengikut cara perkhidmatan anda, seperti `4:00 PTG`. Tinggalkan masa yang sudah diambil.

        <Label htmlFor="time-slot" size="small">Masa temu janji</Label>
        <Select size="small" variant="outline">
          <SelectTrigger id="time-slot">
            <SelectValue placeholder="Pilih masa" />
          </SelectTrigger>
          <SelectContent>
            <SelectItem value="16:00">4:00 PTG</SelectItem>
            <SelectItem value="16:15">4:15 PTG</SelectItem>
            <SelectItem value="16:30">4:30 PTG</SelectItem>
            <SelectItem value="16:45">4:45 PTG</SelectItem>
            <SelectItem value="17:00">5:00 PTG</SelectItem>
          </SelectContent>
        </Select>
      </div>
    </div>
  </Tab>
