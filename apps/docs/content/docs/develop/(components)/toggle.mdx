## Usage

```ts copy title="Import"
import { Label } from "@amerfathullah/myds-react/label";
import { Toggle, ToggleThumb } from "@amerfathullah/myds-react/toggle";
```

```tsx copy title="Anatomy"
export default () => (
  <>
    <Label htmlFor="notify">Email notifications</Label>
    <Toggle id="notify">
      <ToggleThumb />
    </Toggle>
  </>
);
```

The switch has no default name, so name each one. Give the `Toggle` an `id`, and pass the same id to a `Label`'s `htmlFor`, as above. Screen readers then announce the switch by the label's text. Don't wrap the `Toggle` in a `Label`: `ToggleThumb` renders its own `<label>`, and HTML doesn't allow a label inside another label.

If no visible label names the switch, pass an `aria-label` to `ToggleThumb` to name it in your site's language, for example `<ToggleThumb aria-label="Pemberitahuan e-mel" />`. Or pass `aria-labelledby` with the id of an element whose text names it. An `aria-label` replaces a `Label`'s text, so don't pass one to a switch that a `Label` already names.

Space and Enter each toggle the switch. Enter doesn't submit the form it's in.

### Controlled Toggle

Toggle can be handled by Controlled Method

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <div className="flex justify-center">
      <ControlledToggle id="notify-controlled" label="Email notifications" />
    </div>
  </Tab>
  <Tab value="Code">

```tsx
import { Label } from "@amerfathullah/myds-react/label";
import { Toggle, ToggleThumb } from "@amerfathullah/myds-react/toggle";

const ControlledToggle = () => {
  const [isChecked, setIsChecked] = React.useState(false);

  return (
    <div className="flex flex-col items-center justify-center">
      <p>State: {isChecked ? "On" : "Off"}</p>
      <div className="flex items-center gap-3">
        <Label htmlFor="notify-controlled">Email notifications</Label>
        <Toggle
          id="notify-controlled"
          checked={isChecked}
          onCheckedChange={setIsChecked}
        >
          <ToggleThumb />
        </Toggle>
      </div>
    </div>
  );
};
```

  </Tab>
</Tabs>
