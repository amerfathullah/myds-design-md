## Penggunaan

```ts copy title="Import"
import { Label } from "@amerfathullah/myds-react/label";
import { Toggle, ToggleThumb } from "@amerfathullah/myds-react/toggle";
```

```tsx copy title="Anatomi"
export default () => (
  <>
    <Label htmlFor="notify">Pemberitahuan e-mel</Label>
    <Toggle id="notify">
      <ToggleThumb />
    </Toggle>
  </>
);
```

Suis tidak mempunyai nama lalai, jadi namakan setiap suis. Berikan `id` kepada `Toggle`, dan hantar id yang sama kepada `htmlFor` pada `Label`, seperti di atas. Pembaca skrin kemudian menyebut suis itu dengan teks label tersebut. Jangan letakkan `Toggle` di dalam `Label`: `ToggleThumb` memaparkan `<label>` sendiri, dan HTML tidak membenarkan label di dalam label lain.

Jika tiada label yang kelihatan menamakan suis, hantar `aria-label` kepada `ToggleThumb` untuk menamakannya dalam bahasa laman anda, contohnya `<ToggleThumb aria-label="Pemberitahuan e-mel" />`. Atau hantar `aria-labelledby` dengan id elemen yang teksnya menamakannya. `aria-label` menggantikan teks `Label`, jadi jangan hantar `aria-label` kepada suis yang sudah dinamakan oleh `Label`.

Kekunci Space dan Enter masing-masing menukar keadaan suis. Enter tidak menghantar borang yang mengandungi suis itu.

### Dinyahaktifkan

Gunakan prop `disabled` untuk menyahaktifkan suis. `<fieldset>` yang dinyahaktifkan di sekeliling `Toggle` turut menyahaktifkannya. Tetapkan juga `disabled` pada `Label` supaya label malap.

<Tabs items={["Pratonton", "Kod"]}>
  <Tab value="Pratonton">
    <div className="not-prose mx-auto flex w-fit flex-col gap-3">
      <div className="flex items-center justify-between gap-3">
        <Label htmlFor="notify-disabled" disabled>Pemberitahuan e-mel</Label>
        <Toggle id="notify-disabled" disabled={true}>
          <ToggleThumb />
        </Toggle>
      </div>
      <div className="flex items-center justify-between gap-3">
        <Label htmlFor="notify-disabled-checked" disabled>Pemberitahuan e-mel</Label>
        <Toggle id="notify-disabled-checked" disabled={true} defaultChecked={true}>
          <ToggleThumb />
        </Toggle>
      </div>
    </div>
  </Tab>
  <Tab value="Kod">

```tsx
import { Label } from "@amerfathullah/myds-react/label";
```

### Toggle Terkawal

Toggle boleh dikendalikan menggunakan Kaedah Terkawal

<Tabs items={["Pratonton", "Kod"]}>
  <Tab value="Pratonton">
    <div className="flex justify-center">
      <ControlledToggle
        id="notify-controlled"
        label="Pemberitahuan e-mel"
        stateText="Keadaan"
        onText="Hidup"
        offText="Mati"
      />
    </div>
  </Tab>
  <Tab value="Kod">

```tsx
import { Label } from "@amerfathullah/myds-react/label";
import { Toggle, ToggleThumb } from "@amerfathullah/myds-react/toggle";

const ControlledToggle = () => {
  const [isChecked, setIsChecked] = React.useState(false);

  return (
    <div className="flex flex-col items-center justify-center">
      <p>Keadaan: {isChecked ? "Hidup" : "Mati"}</p>
      <div className="flex items-center gap-3">
        <Label htmlFor="notify-controlled">Pemberitahuan e-mel</Label>
        <Toggle
          id="notify-controlled"
          checked={isChecked}
          onCheckedChange={setIsChecked}
        >
          <ToggleThumb />
        </Toggle>
      </div>
    </div>
  );
};
```

  </Tab>
</Tabs>
