### Pemasangan secara Manual

MYDS boleh ditetapkan dengan pelbagai cara, bergantung kepada keperluan projek anda. Namun, cara yang paling mudah mengambil hanya 3-langkah!

<Steps>
  <Step>
    ### Pemasangan pakej
   
     ```package-install
    npm install @amerfathullah/myds-react @amerfathullah/myds-style
    ```
  </Step>

  <Step>

    ### Tetapkan stylesheet CSS<a name="full-css"></a>

    Anda boleh 'import' stylesheet MYDS secara keseluruhan mengikut salah satu cara di bawah.

    __1. Import melalui JS (Bundler)__

    ```ts
    // Letakkan dalam fail permulaan JS/TS (eg. index.{ts,js})
    import "@amerfathullah/myds-style/full.css";
    ```

    __2. Import melalui CSS__

    ```css
    /* Letakkan dalam fail permulaan CSS  */
    @import "@amerfathullah/myds-style/full.css";
    ```

    Untuk tetapan yang lebih lanjut, sila baca [Konfigurasi Style](./style-configuration)

  </Step>

<Step>
    ### Mula menggunakan komponen!

    Cubalah `<Button />` untuk memulakan membina dengan MYDS!

    ```tsx
    import { Button } from "@amerfathullah/myds-react/button";

    export default () => {
      return <Button variant="primary-fill">Hello MYDS</Button>;
    };
    ```

</Step>
</Steps>

### Tidak Menggunakan React?

Komponen MYDS dibina untuk React. Jika projek anda menggunakan teknologi lain, anda masih boleh menggunakan MYDS:

- **Preset Tailwind**: `@amerfathullah/myds-style` berfungsi dengan HTML biasa, jadi kelas utiliti merujuk terus kepada token MYDS yang sebenar. Lihat [Konfigurasi Preset](./style-configuration#konfigurasi-preset).
- **DESIGN.md**: rujukan yang tidak bergantung pada mana-mana framework, menerangkan MYDS token demi token dan komponen demi komponen. Baca di [GitHub](https://github.com/amerfathullah/myds-design-md/blob/main/DESIGN.md).
