## Contoh

### Membina Komponen Tukar Tema

Hook `useTheme` menyediakan cara mudah untuk menguruskan keadaan tema dalam aplikasi anda. Di bawah, kami mentakrifkan komponen tersuai yang membolehkan pengguna menukar antara mod terang dan gelap.

<Tabs items={["Tukar", "Pilih"]}>
  <Tab value="Tukar" className="not-prose">
    ```tsx title="theme-toggle.tsx"
    import { useTheme } from "@amerfathullah/myds-react/hooks";

    const ThemeToggle = () => {
      const { theme, setTheme } = useTheme();

      return (
        <button onClick={() => setTheme(theme === "light" ? "dark" : "light")}>
          Tukar kepada mod {theme === "light" ? "gelap" : "terang"}
        </button>
      );
    };

    export { ThemeToggle }
    ```

  </Tab>
  <Tab value="Pilih">
    ```tsx title="theme-select.tsx"
    import { useTheme } from "@amerfathullah/myds-react/hooks";
    import {
      Select,
      SelectTrigger,
      SelectValue,
      SelectContent,
      SelectItem,
    } from "@amerfathullah/myds-react/select";

    const ThemeSelect = () => {
      const { theme, setTheme } = useTheme();

      const handleChange = (newTheme: string) => {
        setTheme(newTheme);
      };

      return (
        <Select
          size="small"
          variant="outline"
          value={theme}
          onValueChange={handleChange}
        >
          <SelectTrigger aria-label="Tema">
            <SelectValue label="Tema" />
          </SelectTrigger>
          <SelectContent>
            <SelectItem value="light">Terang</SelectItem>
            <SelectItem value="dark">Gelap</SelectItem>
          </SelectContent>
        </Select>
      );
    };

    export { ThemeSelect }
    ```

  </Tab>
</Tabs>

### Mengisytiharkan ThemeProvider yang Boleh Diakses Secara Global

Untuk menggunakan konteks tema di seluruh aplikasi, balut keseluruhan susun atur dengan `ThemeProvider`. Ini memastikan semua komponen anak boleh mengakses keadaan tema dan fungsi tukar. Dalam aplikasi Next.js App Router, `ThemeProvider` dan `useTheme` hanya berfungsi dalam komponen klien, jadi susun atur ini bermula dengan `"use client"`.

```tsx title="layout.tsx"
"use client";

import type { ReactNode } from "react";
import { ThemeProvider } from "@amerfathullah/myds-react/hooks";
import { ThemeToggle } from "./theme-toggle";

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <ThemeProvider>
      <div className="app-container">
        <ThemeToggle />
        {children}
      </div>
    </ThemeProvider>
  );
}
```
